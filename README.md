## 在线工具

### [对照 · 文本对比工具](https://kiritoko1029.github.io/kiritoko1029/)

一个完全在浏览器本地运行的文本对比工具：

- 支持粘贴文本和从本地导入文件
- 支持大文本对比与 Web Worker 后台计算
- 支持行级／字符级差异高亮
- 支持忽略行内空白、忽略大小写和仅看差异
- 支持分页浏览、差异跳转、复制报告和导出 TXT

> 文本与文件只在当前浏览器中处理，不会上传到服务器。
